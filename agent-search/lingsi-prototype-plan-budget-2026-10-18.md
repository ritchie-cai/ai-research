# 灵思：25.4 mm 可换壳立方体样机路径与前期预算

日期：2026-10-18。此稿用于询价与立项，金额为人民币规划区间，**不是供应商报价**。先读[市场验证与空间测算](lingsi-market-validation-2026-10-18.md)，技术前提见 [硬件选型](lingsi-hardware-selection-2026-10-18.md)。

第一次做硬件请先按[完整开发操作手册](lingsi-hardware-development-playbook-2026-10-18.md)执行；本页主要保留分阶段费用与供应商拆分。**市场验证先于完整硬件立项**：用两周访谈、连续使用、订金和活动采购意向决定是否进入开发板与 EVT，市场验证现金规划约 ¥0–3,000，不含创始人时间。

## 先用几百元验证核心链路

上一版的 24–60 万元是“25.4 mm、独立蜂窝、可换壳、云端与小程序完整集成的外包工程样机”预算，**不是启动探索的最低门槛**。若创始团队自己写脚本和简易后端，可以先不打 PCB，按以下顺序投入：

| 级别 | 做什么 | 现金采购预算（非报价） | 能回答什么 |
|---|---|---:|---|
| A. 开发板闭环 | 采购一套[移远 EC800M Audio 核心板](https://github.com/QuecPython/EC800M_Audio_Core_Board)、SIM/流量、USB 电源；使用板载麦克风和[录音 API](https://developer.quectel.com/doc/quecpython/API_reference/en/medialib/audio.Record.html)，经 4G 上传到自己控制的测试服务，调用少量 ASR/LLM，先在网页或微信开发预览中查看。 | **约 300–800 元**；按板卡、SIM、配件和少量云/API 用量预留，购买前看实时价格。 | 用户会不会真的按下录音、上传和回看？五分钟文件是否能保存、转写？网络体验如何？ |
| B. 外壳交互演示 | 在 A 的基础上，用现成 NFC 标签、简单读卡模块和较大 3D 打印外壳演示“装壳领取”，用外接按键演示投票。 | **再加约 300–1000 元**，需按模块、加工方式实价调整。 | 领取与互动的产品逻辑是否直观；**不能**验证 25.4 mm 内的 NFC/天线共存。 |
| C. 外观/尺寸概念件 | 仅打印 25.4 mm 圆角立方体及可换壳，用配重和纸面 PCB/电池体积块做装配体验。 | **约 100–500 元**。 | 尺寸、握感与换壳方式是否成立；不是可独立联网的真机。 |
| D. 自己设计首版 PCB | A/B 得到反馈后，由团队自行画原理图与 PCB，委托嘉立创制作、贴片，结构仍可粗糙；预留几轮修板。 | **约 2000–10000 元物料与加工预留**，开发者时间与仪器另计。 | 能否把板级功能合在一起；不保证一次达到 25.4 mm、可靠性或认证要求。 |

A 的现金预算成立条件：开发板价格落在几百元内、已有电脑与开发者、可使用少量云/API 额度，研发时间不计现金。如果要外包固件、云端或微信小程序，费用会增加；几百元只是物料和试用费。移远官方的[Audio 核心板](https://github.com/QuecPython/EC800M_Audio_Core_Board)带 MIC、天线/电池/SIM 接口，官方[示例](https://developer.quectel.com/doc/quecpython/API_reference/en/medialib/audio.Record.html)提供录音文件读写方法；实际固件版本、可用空间、五分钟时长、音质和上传方式仍要亲测。第一周先用 USB 供电，暂不碰微型电芯。对 A 级演示，先用简单网页或微信开发预览展示结果，正式小程序发布留到有人愿意连续使用之后。

**嘉立创何时介入：**只有当开发板链路证明有价值、并且已画出原理图/PCB 后，才下单 PCB 或 PCBA。其[官方报价结构](https://jlcpcb.com/help/article/pcb-assembly-price)显示经济型贴片 setup 约 US$8.18，板材、器件和其他工序另算；它能大幅降低制造费，却不会自动完成原理图、射频、电源、固件和尺寸调试。若采用移远公开的音频板资料作为参考，先核对设计文件及使用许可，再做适合产品的改版。

## 定义“做成一件成品样机”

交付一件可拿在手中反复演示的国内版圆角立方体，**换壳后长、宽、高各 ≤25.4 mm**。至少包含：长按录音最长五分钟、断网暂存并通过蜂窝网传至自有云、云端 ASR 与整理、微信小程序查看与编辑；装上含 NFC 的联名壳自动领取内容；活动时间窗口内用按键投票或表达情绪；设备仅发本地状态音。近场匹配和震动暂不纳入首件验收。外观可以达到展示品质，但此阶段不宣称已满足量产可靠性或上市认证。

为了交付这一件，通常要同时制作 5–10 块电子板、若干结构件和至少两轮装配，保留破坏性测试与返修余量。不要把目标理解成“只加工一个零件”。

## 分阶段实施与付款闸门

| 阶段 | 工作、可验收交付物 | 时间估算 | 外包现金预算 |
|---|---|---:|---:|
| 0. 设计冻结和风险验证 | 功能规格、25.4 mm 三维堆叠图、物料与接口表；用移远开发板验证五分钟录音及编码/上传；向电芯厂索取微型高倍率电芯并以峰值电流、低电量、弱网做台架测试；天线/NFC/壳体材料预评估。**电池与射频无法装入则停止完整小型化委托。** | 2–4 周 | 3–8 万 |
| 1. 定制硬件及固件 | 原理图、PCB、Gerber/BOM/CPL、5–10 块 PCBA；充电底座、按键、麦克风、存储、NFC、供电与 Cat.1 固件；20–30 个结构/外观件用于装配迭代。 | 5–9 周 | 10–22 万 |
| 2. 云及微信端 | 自有云设备注册、加密暂存上传、断点续传与幂等、ASR/LLM 流水线、领取权益账本、活动投票后台；微信小程序的配对/列表/编辑/活动入口。可与阶段 1 并行。 | 4–8 周 | 6–15 万 |
| 3. 整机联调与修板 | 至少两轮主板/结构迭代，天线与 NFC 调试，录音、充电、按键、壳体、弱网、跌落/反复拆装测试；交付 1 件展示样机、维修备件、测试数据与全部设计源文件。 | 4–6 周 | 5–15 万 |
| **合计** | 阶段 1/2 并行，整体按保守排期 | **约 12–20 周** | **约 24–60 万** |

预算口径：按核心研发以珠三角外包、两次 PCB/结构修改、少量样机加工、基础云端与小程序功能计；不是单件 BOM。上限含尺寸受限带来的返工缓冲。云服务持续费、SIM 流量、后续模型调用量、品牌联名授权、注塑模具、销售认证和 30–100 台试产均单列。若创始团队自己承担固件、后端、小程序，现金支出可显著降低，但人力投入仍在。

## 珠三角现成能力的采购拆法

| 能力 | 采购建议 | 询价资料与注意点 |
|---|---|---|
| 蜂窝平台 | 先采购 [移远 EC800M-CN 开发板/核心板](https://developer.quectel.com/modules-cat/ec800m-series)与国内测试 SIM；让移远或其代理参与原理图、天线和音频设计评审。移远公开资料列有设计审查、天线、RF/功耗/音频测试支持。 | 先确认 QuecOpen/QuecPython 固件版本、录音编码、Flash/SPI 与网络接口；索取可采购料号及数量阶梯报价。 |
| PCB、器件与贴片 | 向深圳 PCB/PCBA 平台（如 [PCBWay](https://www.pcbway.com/why.html) 或 [JLCPCB](https://jlcpcb.com/help/article/pcb-assembly-price)）分别询价。标准板优先用现成 SMT 线；细间距、叠板、柔性板或手装另询。 | 平台的低打样费只覆盖已有生产文件后的制造/贴片；原理图、射频、电源、固件与整机调试需另外采购。JLCPCB 的公开价显示贴片 setup 约 US$8–51，器件与其他工序另计。 |
| 外壳与装饰 | 首件用树脂/尼龙 3D 打印和局部 CNC/喷涂；先做塑料壳、非金属装饰壳，再验证带金属元素的联名壳。[JLC3DP](https://jlc3dp.com/news/materials-finishing-pricing-update-july2026)提供上传模型后实时报价。 | 所有壳均保留收音、按键、充电、蜂窝射频与 NFC 窗口，先用拆装夹具验证。单件不要先开注塑模。 |
| 电池与充电 | 找珠三角微型软包电芯厂/电池包厂做 2–3 家并行询证，例如深圳有异形电池研发和生产基地的[格瑞普](https://www.grepow.com/contact-us.html)可作为询价对象；索取尺寸、持续/脉冲放电曲线、保护板、运输资料。充电底座用标准弹针或磁吸结构打样。 | **这是第一付款闸门**。移远[硬件手册](https://developer.quectel.com/wp-content/uploads/2024/09/Quectel_EC800M-CNEG810M-CN_QuecOpenQuecPython_%E7%A1%AC%E4%BB%B6%E8%AE%BE%E8%AE%A1%E6%89%8B%E5%86%8C_V1.3.pdf)要求约 2 A 电源能力；未找到已验证能在当前净空内满足此需求的现货电芯。不能拿普通 2C 小电池代替。 |
| NFC 标签 | 先用原厂标签/安全标签现货与打印贴片；申请 NTAG 424 DNA 个性化服务报价，首件可写入测试身份；云端领取必须校验与幂等。 | 金属或厚涂层影响耦合；不同材质须分别测装壳读取成功率。不要让外壳供应商只交印刷 UID。 |
| 声学、射频和整机 | 在深圳找有蜂窝小型设备经历的设计公司/实验室做一轮测量；结构加工可分给深圳/东莞快速打样厂，最后由一家主集成商负责总装。 | 要求实测数据：峰值电流、电压跌落、天线效率/驻波、麦克风噪声、音效可闻性、温升与尺寸。 |

**合同写法：**阶段 0 单独签、单独验收；其后再签定制开发。总包可以一家牵头，但模块、电池、PCB、结构与云端分别对比报价。写明源文件交付（原理图、PCB、CAD/STEP、固件源码与构建方式、测试脚本、后台与小程序源码、BOM、维修资料）、知识产权归属、测试工装、返工次数和失败退出条件。按里程碑付款，避免只拿到一件不可修改的黑盒样机。

## 第一轮验收数据

1. **几何：**最厚外壳装上后，三轴均 ≤25.4 mm；记录公差、重量、圆角与手持按键误触情况。
2. **供电：**满电、低电、低温及弱信号上传时无复位；记录 2 A 供电路径的电压跌落、热像、实际可录次数和待机时长。
3. **录音：**连续五分钟无丢帧；断电/断网后片段可恢复；安静与嘈杂环境各录样本，给出 ASR 错误示例和用户可理解的失败提示。
4. **同步：**至少两家国内运营商、室内/室外/人群密集场景；统计文件上传成功率与 P50/P95 延时。录音完成音只表示本地已保存，云端到账由小程序确认。
5. **换壳：**不同材质/厚度各装卸至少几十次，测 NFC 首次读取率、重复领取防护和拆下后权益保留；验证壳未堵麦克风与天线。
6. **活动：**离线按键事件缓存、重复投票规则、活动结束后回传、后台计票审计；小程序展示状态和权益。

## 立项决策与上市边界

当前最值得先做的是 **M0 市场验证**：真实录音与回看、明确价格下的订金、主办方有预算的书面试点意向。通过预设门槛后，由团队自己完成 A 级几百元开发板闭环。确认有人持续使用或愿意采购后，再投入阶段 0 的 3–8 万元评估一英寸独立联网结构：如果没有合适电芯，或蜂窝天线在完整联名壳下无法工作，25.4 mm 的独立联网版本就不能按当前定义承诺交付。此时需要在尺寸、电池续航、联网方式或功能完整度中调整条件，再批准阶段 1。若基础物理条件通过，才将完整外包样机按 24–60 万元规划，并让供应商依据 CAD、BOM 和验收指标给正式报价。

样机成功不等于可公开销售。国内蜂窝成品的进网许可适用性、无线电型号核准及运营商接入应在试产前由检测机构/运营商核定；[工信部《电信设备进网管理办法》](https://www.miit.gov.cn/zcfg/xxtxl/art/2024/art_773927399a0a4864b47dfab2ba120302.html)规定纳入目录的公用网终端须取得许可。量产模具、认证、可靠性、隐私与数据治理、售后体系需另作预算。海外版另选匹配欧美频段的模组与部署区域，不把国内样机直接当成海外销售样机。
